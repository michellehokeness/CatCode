# CatCode
Cat behavior translator
This is an interactive website that focuses on decoding cat behavior, body language and communication signals.
It is a blend of informational content, playful UX and accessible front-end development to help users better understand their cat(s).

This website is a project built for my portfolio and learning experience with a focus on structure and accessibility. Will eventually incorporate database and CMS.

## Project Concept

Cats communicate through posture, tail position/movements, ear movements, vocalization, and behavior patterns and people often miss or misinterpret those signals.

CatCode acts as a "behavior translator" by breaking down common cat behaviors into clear, readable explanations.
The goal is to create a website that is:

1. Educational yet approachable (fun)
2. Visually simple and readable
3. Easy to navigate - especially on mobile
4. Built with accessibility and semantic HTML

## Features

1. Responsive, mobile-first
2. Behavior category cards and decoder panels
3. Body part icons that take user directly to the areas they have questions about
4. Clean black and white visual system with subtle interaction states
5. Accessible navigation and content structure
6. CSS-only hamburger menu

Planned and Still in Progress:
1. Dynamic behavior decoder (database-driven)
2. Product recommendation cards that tie to behaviors
3. CMS rebuild after static version
4. search feature
5. Performance and SEO optimization

## Accessibility Focus

CatCode is designed with accessibily in mind:

1. Heading heirarchy
2. Keyboard navigable menus
3. High contrast color palette
4. Descriptive link text
5. Screen-reader-friendly structure
6. WCAG-aware design decisions (accessibility is not an afterthought)

## Purpose

This project servers several purposes:
1. Possible coursework for web development classes
2. Portfolio Piece
3. Creative fun

CatCode is intentionally built in phases, starting with static and then growing more dynamic over time.
